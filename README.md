# Doc-classifier

## Local development

Create a `.env` file with `GROQ_API_KEY`, then run:

```powershell
python manage.py runserver
```

## Deploy on Render

Create a Render Web Service from this repository. The included `render.yaml` uses:

- Build: `pip install -r requirements.txt && bash build.sh`
- Start: `gunicorn core.wsgi:application`

Set `GROQ_API_KEY` in the Render environment variables. `DJANGO_SECRET_KEY` is generated by Render. This project is stateless and does not require a database; uploaded files and extracted data are processed in memory only.
